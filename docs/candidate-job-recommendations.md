# پیشنهاد شغل قابل توضیح

پیشنهادها صرفاً از مهارت‌های رزومه، ترجیحات شغلی ثبت‌شده و فیلدهای عمومی آگهی ساخته می‌شوند. هیچ
API هوش مصنوعی، embedding، داده حساس یا داده خصوصی کارفرما استفاده نمی‌شود.

## امتیازدهی

- هر مهارت مشترک یکتا: ۱۰ امتیاز
- شهر ترجیحی: ۴ امتیاز
- نحوه حضور ترجیحی: ۳ امتیاز
- نوع همکاری ترجیحی: ۳ امتیاز
- سطح شغلی ترجیحی: ۳ امتیاز
- تطابق شهر رزومه، فقط وقتی شهر ترجیحی ثبت نشده: ۲ امتیاز

نبود یک ترجیح امتیاز منفی ندارد. آگهی زمانی واجد پیشنهاد است که حداقل یک مهارت مشترک یا حداقل دو
ترجیح صریح منطبق داشته باشد. خروجی بر اساس امتیاز، تعداد مهارت مشترک، زمان انتشار و در پایان UUID
مرتب می‌شود. این امتیاز احتمال استخدام یا درصد سازگاری آماری نیست و در UI به‌صورت عدد نمایش داده نمی‌شود.

حداکثر ۲۰ نتیجه از PostgreSQL بازگردانده می‌شود. فقط آگهی‌های مشمول policy عمومی انتشار/انقضا وارد
query می‌شوند و درخواست‌های قبلی همان Candidate با `NOT EXISTS` حذف می‌شوند.

## وابستگی استقرار

این قابلیت migration جدید یا environment variable جدید ندارد، اما به جدول
`candidate_job_preferences` از migration `0013_regular_silvermane.sql` وابسته است. قبل از استقرار باید
وجود این جدول، foreign key و constraintهای آن با query فقط‌خواندنی تأیید شود. migrationهای feature-gated
بعدی، از جمله Saved Jobs، فقط در صورت فعال بودن flag مربوطه query می‌شوند.
