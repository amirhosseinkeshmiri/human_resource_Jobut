# آگهی‌های ذخیره‌شده کارجو

این قابلیت به migration شماره `0022_mute_warpath.sql` وابسته است و به‌صورت پیش‌فرض خاموش می‌ماند.

ترتیب فعال‌سازی production:

1. از PostgreSQL نسخه پشتیبان مستقل تهیه و امکان بازیابی آن را بررسی کنید.
2. migration شماره 0022 را یک‌بار، به‌صورت دستی و پس از migrations قبلی اجرا کنید.
3. وجود جدول، کلید اصلی مرکب و foreign keyها را بررسی کنید.
4. نسخه جدید برنامه را با `CANDIDATE_SAVED_JOBS_ENABLED=false` deploy و سلامت مسیرهای فعلی را بررسی کنید.
5. مقدار `CANDIDATE_SAVED_JOBS_ENABLED=true` را در محیط Runflare ثبت و برنامه را restart کنید.
6. با یک حساب آزمایشی کارجو ذخیره، حذف، صفحه‌بندی و جداسازی حساب‌ها را smoke-test کنید.

تا پیش از فعال‌سازی دقیق مقدار `true`، ناوبری و کنترل‌ها نمایش داده نمی‌شوند و برنامه جدول جدید را query نمی‌کند.
