# منبع شهرهای ایران

فایل `src/lib/iran-cities-data.json` از خروجی سال ۱۴۰۴ مخزن
[`Hameds/IranCountryDivisions`](https://github.com/Hameds/IranCountryDivisions) تولید شده است. مخزن بالادستی
فایل اصلی سالانه مرکز آمار ایران را نگهداری می‌کند، خروجی خود را تحت مجوز MIT منتشر کرده و SHA-256 فایل
JSON دریافت‌شده برای این نسخه برابر است با:

```text
d493adef35d7b7187ce3c14b69794f0f6c66b4a9c9cdbfe9834cdb00e026e9e0
```

اعلان کامل مجوز و حق مؤلف بالادستی در
`docs/third-party/iran-country-divisions-LICENSE.txt` نگهداری می‌شود.

## پوشش

- سال مرجع: ۱۴۰۴ هجری شمسی
- استان: ۳۱
- شهر واقعی (`DivisionType = 5`): ۱۴۸۱ رکورد
- منطقه شهری (`DivisionType = 7`): ۱۹۱ رکورد، عمداً خارج از انتخابگر شهر

«منطقه شهری» زیرمجموعه یک شهر بزرگ است و نباید به‌عنوان شهر مستقل در فیلتر فرصت شغلی نمایش داده شود.
رکوردها از مسیر والد بخش ← شهرستان ← استان به استان مربوط متصل شده‌اند. `Code` منبع به‌عنوان کلید یکتای
رکورد نگهداری می‌شود؛ بنابراین شهرهای هم‌نام در استان‌های مختلف ادغام نمی‌شوند.

## سازگاری JobUT

پارامتر فعلی `location` و ستون آگهی هر دو نام شهر را به‌صورت رشته ساده نگه می‌دارند. combobox برای رفع
ابهام نام استان را نمایش می‌دهد، اما فقط نام شهر را در query string ارسال می‌کند تا URLهای قبلی و تطبیق
دقیق فعلی PostgreSQL تغییر نکنند. در نتیجه انتخاب دو شهر هم‌نام در دو استان، با مدل داده فعلی به یک مقدار
`location` منجر می‌شود. رفع کامل این ابهام نیازمند مدل جداگانه city code/province در آگهی و migration است و
در این تغییر عمداً انجام نشده است.

## محدودیت اعتبار

این snapshot ادعای به‌روز بودن پس از پایان سال ۱۴۰۴ ندارد. مخزن بالادستی رسمی دولتی نیست، اما فایل منبع
مرکز آمار، فرایند تبدیل و داده خروجی را برای بازتولید نگهداری می‌کند. هر انتشار آینده باید در برابر فایل
سالانه جدید مرکز آمار یا اعلام‌های وزارت کشور بررسی و با hash و تعداد رکورد جدید ثبت شود.
