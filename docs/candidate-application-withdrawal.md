# انصراف کارجو از درخواست استخدام

این قابلیت به migration شماره 0023 وابسته است و با `CANDIDATE_APPLICATION_WITHDRAWAL_ENABLED=false` خاموش می‌ماند.

ترتیب فعال‌سازی production:

1. ابتدا migrations قبلی، از جمله 0022، را مطابق دفتر migration پروژه تعیین تکلیف کنید.
2. از PostgreSQL پشتیبان مستقل تهیه و بازیابی آن را بررسی کنید.
3. migration شماره 0023 را یک‌بار دستی اجرا و وجود مقدار `withdrawn` در enum `application_status` را به‌صورت read-only تأیید کنید.
4. نسخه جدید را با feature flag خاموش deploy و مسیرهای فعلی کارجو و کارفرما را smoke-test کنید.
5. مقدار `CANDIDATE_APPLICATION_WITHDRAWAL_ENABLED=true` را تنظیم و برنامه را restart کنید.
6. انصراف از وضعیت‌های دریافت‌شده، در حال بررسی و مصاحبه و نمایش آن در پنل کارفرما را با داده آزمایشی بررسی کنید.

انصراف، درخواست یا snapshot رزومه را حذف نمی‌کند و محدودیت یکتای کارجو/آگهی همچنان درخواست مجدد را مسدود می‌کند.
